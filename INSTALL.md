# Installation & Setup Guide

**Overhaul AI Command Center** — an AI-powered supply chain risk-intelligence
platform built with Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS
v4, and Framer Motion.

This guide takes you from the zip file to a running app in about 5 minutes.

---

## 1. Prerequisites

Install these once on the machine:

| Tool | Version | How to check | Where to get it |
|------|---------|--------------|-----------------|
| **Node.js** | 20 LTS or newer | `node -v` | <https://nodejs.org> (download the **LTS** build) |
| **npm** | 10 or newer (ships with Node) | `npm -v` | included with Node.js |

> No database, Docker, or other services are required — everything runs locally
> in Node.

---

## 2. Open the project folder

Clone or open the project, then open a terminal **inside** the repo root:

```bash
cd overhaul-ai-command-center
```

You should see `package.json`, `src/`, and `public/` in this directory
(`ls` / `dir` to confirm).

> **Note:** `node_modules/` and `.next/` are not committed — they are
> regenerated by the steps below. `.env.local` is also git-ignored (it may
> hold a private API key). Use `.env.example` as your template — see step 4.

---

## 3. Install dependencies

```bash
npm install
```

This downloads all packages into a local `node_modules/` folder (a few hundred
MB). First run takes 1–3 minutes.

> Seeing an `EBADPLATFORM` / "unsupported platform" error here? You're not on an
> Apple-Silicon Mac — jump to **Troubleshooting → Platform error** below, it's a
> 30-second fix.

---

## 4. (Optional) Configure the AI key

The app works out of the box **without any key** — the AI copilot, briefings,
and reports fall back to built-in mock responses so the demo always runs.

To enable **real** AI (Claude), create your local env file from the template and
add an Anthropic API key:

```bash
cp .env.example .env.local
```

Then open `.env.local` and set:

```
ANTHROPIC_API_KEY=sk-ant-your-key-here
```

Get a key at <https://console.anthropic.com>. `.env.local` is git-ignored and
should **never** be committed or shared.

| Feature | Without key | With `ANTHROPIC_API_KEY` |
|---------|-------------|--------------------------|
| Copilot chat | Deterministic mock replies | Claude Haiku, streamed, with tool-calling |
| Executive briefing / incident report / route advice | Static templates | Claude Sonnet reasoning over live data |

---

## 5. Run it

### Development (hot-reload, for local review)

```bash
npm run dev
```

Open **<http://localhost:3000>** in your browser. Edits to source files reload
automatically.

### Production (optimized build)

```bash
npm run build   # compiles an optimized production build
npm run start   # serves it on http://localhost:3000
```

## 7. Troubleshooting

**Platform error on `npm install`** (`EBADPLATFORM` /
"Unsupported platform for @next/swc-darwin-arm64" or
"lightningcss-darwin-arm64")

Older zip copies pinned Mac-only binaries in `package.json`. The current repo
no longer lists those packages — delete `node_modules` and `package-lock.json`,
then run `npm install` again so Next.js and Tailwind pull the correct platform
binaries.

---

**Port 3000 already in use**

Run on a different port:

```bash
npm run dev -- -p 3001
```

Then open <http://localhost:3001>.

---

**`npm install` fails or behaves oddly**

Clear and reinstall:

```bash
rm -rf node_modules package-lock.json   # Windows: delete the folder + file manually
npm install
```

---

**Node version errors**

Confirm you're on Node 20+ (`node -v`). If you juggle multiple Node versions, use
[nvm](https://github.com/nvm-sh/nvm): `nvm install 20 && nvm use 20`.

## 8. Quick reference (copy-paste)

```bash
# from inside the unzipped folder:
npm install          # 1. install dependencies
cp .env.example .env.local   # 2. (optional) then add ANTHROPIC_API_KEY
npm run dev          # 3. start → http://localhost:3000
```

That's it. If anything above doesn't match what you see, the canonical scripts
live in `package.json` and the AI notes are in `README.md`.
